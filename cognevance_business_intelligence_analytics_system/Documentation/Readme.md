# Business Intelligence Analytics System

## Project Overview

This project was developed as part of the Cognevance Technologies Data Analytics & Business Intelligence program.

The objective is to build a complete Business Intelligence solution using Python, PostgreSQL, and Power BI. The project includes data preprocessing, ETL, SQL database integration, dashboard development, and predictive analytics.

---

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- PostgreSQL
- Power BI
- Jupyter Notebook

---

## Dataset

Retail Sales (Superstore) Dataset

Files:
- supermarket.csv
- cleaned_supermarket.csv

---

## ETL Process

- Extract sales dataset
- Clean missing values
- Convert date columns
- Rename columns
- Load cleaned data into PostgreSQL

---

## Dashboard Pages

- Home
- Executive Dashboard

- Customer Analysis
- Product Analysis
- Predictive Analytics

---

## Predictive Analytics

A Linear Regression model was developed to forecast future monthly sales.

Outputs:

- sales_forecast.csv
- model_metrics.csv

---

## Business Insights

- Technology category generated the highest sales.
- West region recorded the highest revenue.
- Forecast results indicate gradual sales growth.
- Customer segmentation supports targeted marketing.
